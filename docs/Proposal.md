# Propuesta
El entorno de ejecución es la rotonda del arco del triunfo junto con su círculo externo. Esto permite a los automóviles transitar entre ambas vialidades cambiando entre calles, dando vueltas, integrándose e incorporándose, sin tener que abandonar el entorno de simulación. Una característica importante de esta vialidad es que no cuenta con semáforos, por lo que se propone un modelo en donde los coches sean los únicos agentes y sigan el modelo de teoría de juegos. Para proceguir, se tienen dos propuestas:
1. Los agentes se encuentran en intersecciones y siempre toman la decisión más conveniente para ellos, según una matriz de pagos. Esto hará que siempre se tienda a un equilibrio de Nash, que puede no ser un óptimo global. Sin embaro, la vital diferencia entre este entorno y un dilema del prisionero con repetición es que los coches nunca se encuentran en situaciones exactamente iguales; uno de ellos se encuentra en una rotonda (o el loop exterior), mientras que el otro se encuentra sobre una calle. De esta forma, la propuesta es utilizar un algoritmo de reinforcement learning para calcular las matrices de pago tal que su equilibrio de Nash sea equiparable con el máximo global.
2. Utilizar teoría de juegos (más específicamente el uso de coaliciones) para generar mediante algún coordinador (un GPS, reglas viales o etc) la distribución de coaliciones y pagos tal que los vehículos se comporten siguiendo un óptimo global. Para más detalle de lo que se ha trabajado en clase, véase el @./Ejemplo_coaliciones.pdf. Este **no necesariamente** debe mantenerse para el proyecto, pero muestra hasta dónde se ha llegado en cuanto a este aspecto.
